# Old vs new nutrient sourcing

Generated by `npx --yes tsx scripts/eval/compare.mts --web` against the live Supabase reference data and `gpt-4o-mini`.

**What this measures.** No photos are involved: each food is described in text with the same grams on both sides, and one
model call returns its own nutrient guess plus search terms and ingredients.
- **Old** = the model's own nutrient guess (what the previous photo route stored: recall).
- **New** = the grounded pipeline: built-in table, then IFCT/USDA search, then recipe summed from IFCT/USDA ingredients
  (a second small model call lists the ingredients when the model gave none), then live web search, then the model's guess.

**What it does not measure.** Whether the model identifies the food or the portion correctly from a photo. That needs real
photos. Model output varies slightly between runs, so individual rows move a little each time. There is no ground truth
column: "new" is database/recipe/web data, which is better grounded but not exact for composite dishes.

## What the run shows
- **Recall runs high on Indian dishes.** Idli 440 vs 240 kcal, dal tadka 400 vs 232, butter chicken 600 vs 300, upma 570 vs 360.
  These are the foods the old approach got most wrong, and the grounded values sit close to published composition data.
- **Staples agree.** Banana, egg, cooked rice, chicken breast, pizza and cheeseburger match within a few percent, so grounding
  does not disturb cases the model already got right.
- **Web fallback rescues dishes with no database row.** Ragi mudde: the model's own guess was 720 kcal for 200 g in one run;
  grounded web value 230 kcal. Rajma curry, bajra roti and coconut chutney also resolve this way.
- **Recipe sums are the least certain.** They depend on the ingredient weights the model lists. Pav bhaji and peanut chutney
  still land well below the model's guess and may be low; the pipeline sends recipes that disagree with the model by more than
  2x to a web check, and lowers confidence when that finds nothing.
- **Known weak matches.** Cooking oil sometimes resolves to an odd USDA oil row (kcal is similar, so harmless), and "steamed white
  rice" picked a restaurant-rice row (+16%) because the built-in table's labels are less specific than the query.
